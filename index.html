How NexusCall works

NexusCall uses PeerJS for WebRTC signaling — no custom server needed.

To start a call:

  1. Click "Create Room" — allow camera/mic.
  2. Share the 6-digit code or invite link with your partner.
  3. They click "Join Room", enter the code — connected!

Privacy

Video streams are encrypted with DTLS-SRTP directly between browsers. PeerJS only handles the handshake — it never sees your media.
