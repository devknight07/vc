How Static Calling Works

Since this app has no centralized media servers, it runs completely inside your browser client. This means it can be safely hosted on static hosts like GitHub Pages!

Manual P2P Mode (Recommended)

  1. Grant camera access, then click "Start Room" to generate your offer.
  2. Copy your Connection Token and send it to your peer over your preferred secure messenger.
  3. The peer clicks "Join Friend", pastes your token, and generates their response token.
  4. The peer sends their response token back to you. Paste it and complete the connection handshake.

Automatic Cloud Mode

When deployed with environment keys, Cloud Mode automatically exchanges these keys behind the scenes over Firebase, giving you zero-click access via simple 6-digit room IDs.
